# Sales Process

## When to apply
- Designing qualification criteria, demo scripts, pricing/proposal templates, or CRM pipeline automation.
- Auditing conversion bottlenecks between qualified leads and closed deals.

## Procedure
1. Define clear pipeline stages with objective exit criteria (e.g., discovery completed, technical validation, security review).
2. Anchor discovery questions on quantified customer pain, existing workflow cost, decision timeline, and technical blockers.
3. Prepare reusable technical one-pagers and security/architecture FAQs backed strictly by implemented product capabilities.
4. Log deal blockers, champion feedback, and loss reasons consistently in structured CRM fields.
5. Never automate unsolicited bulk outreach or make unverified product/roadmap promises in proposals.

## Verification
- Pipeline stage definitions have zero ambiguous overlap.
- Technical claims in sales collateral match current documented capabilities.
